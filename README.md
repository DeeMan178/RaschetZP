# 🏭 Калькулятор заработной платы (Сменный график)

Компактное, быстрое и полностью автономное веб-приложение для расчета заработной платы. Разработано специально для удобного учета рабочих смен, дополнительных часов (накат, сушка) и вычета авансов. Идеально подходит для производственных графиков.

Приложение реализовано в формате **Single-File App** — вся структура (HTML), стили (CSS) и логика (JavaScript) находятся в одном легковесном файле, который работает без интернета и серверов.

## ✨ Ключевые возможности

* 📱 **Mobile-First дизайн:** Интерфейс спроектирован так, чтобы идеально помещаться на одном экране смартфона без необходимости вертикальной прокрутки.
* 💾 **Автоматическое сохранение:** Все введенные настройки (ставки) и текущие расчеты мгновенно сохраняются в локальной памяти браузера (`LocalStorage`).
* 📊 **Журнал выплат:** Встроенная история по месяцам для ведения личной статистики доходов.
* 📸 **Режим скриншота (Read-Only):** Специальная кнопка, скрывающая все лишние элементы интерфейса (рамки, поля ввода, кнопки) для создания чистого и аккуратного скриншота-отчета.
* 📤 **Web Share API:** Формирование текстовой сводки (Итого, к выдаче, отработанные часы) и отправка ее в мессенджеры в один клик (или копирование в буфер обмена).
* 🛡 **Отказоустойчивая архитектура:** Навигация по вкладкам построена на аппаратном CSS (`input type="radio"`), а математика написана на базовом стандарте JavaScript (ES5), что гарантирует работу даже в старых и встроенных WebView-браузерах.

## 🛠 Технологический стек

* **HTML5** (Семантическая структура)
* **CSS3** (Flexbox, CSS-переключатели, нативные переменные)
* **Vanilla JavaScript** (Без сторонних библиотек, фреймворков и зависимостей)

## 🚀 Как использовать (Установка)

Так как проект не имеет зависимостей, его не нужно собирать через Node.js или настраивать сервер.

**Вариант 1: Использование онлайн**
Просто перейдите по ссылке (здесь будет ссылка на твой GitHub Pages, если ты его включишь).

**Вариант 2: Локальное использование**
1. Скачайте файл `index.html` из этого репозитория.
2. Откройте его в любом современном браузере на телефоне или ПК (Chrome, Safari, Яндекс.Браузер).
3. Добавьте страницу на "Главный экран" смартфона для быстрого доступа.
